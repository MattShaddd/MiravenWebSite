# Проверка регрессий Miraven — 2026-10-05

Список восстановлен из сообщений пользователя после переключения на Luna 2026-10-04 (17:36–19:49 по Новосибирску). Не все старые жалобы были подтверждены заново на реальных устройствах.

## Исправления и критерии проверки

| Проблема | Что изменено / что проверять |
|---|---|
| Карточка не скроллится, покупка за экраном | Убраны конфликтующие мобильные overflow/height; один контейнер прокрутки, покупка fixed снизу. Проверено в браузере на 390×844, покупка на публичной странице добавила товар. |
| Кнопки и кружки искажаются | Кнопки карточки имеют фиксированные размеры и flex:none. На 320×568 все верхние кнопки 42×42; стрелки общего просмотрщика квадратные. |
| Фото открываются по-разному | Общий image-viewer включён в catalog.js и qv.js; его CSS загружается самим модулем. Прямой вход в каталог раньше активировал старый fallback без общего модуля. |
| Двойной клик увеличивает фото на кадр | Основной просмотр идёт через общий модуль без dblclick-зумирования. Старый fallback остаётся в исходнике для совместимости; исходное незакоммиченное изменение qv.js сохранено. |
| Свайпы фотографий переключают товар | Жест внутри галереи больше не переключает товар; touchcancel сбрасывает начатый жест. Реальные touch-сценарии требуют проверки на устройствах. |
| Свайп вниз и крестик | Оба закрывают через closeQV; полноэкранная карточка больше не расширяется как шторка. Общий просмотрщик имеет закрытие свайпом вниз. |
| Меню категорий тормозит | По решению пользователя большой список остаётся в начале каталога; отдельный fixed-список появляется под шапкой. Анимация height удалена, переход использует transform/opacity. |
| Щель под шапкой | Позиция мини-меню следует за фактическим border-box шапки. В публичной проверке панели перекрываются на 1 px. |
| Главная и каталог имеют разные кнопки | product-card.js/.css переиспользуются; общий feedback используется также внутри карточки товара. |
| Первый полёт в корзину кривой | Координаты кнопки снимаются до вызова Tilda, который может заменить DOM. Общая анимация использует transform; тест покрывает первый полёт и скрытую desktop-корзину. |
| Вибрация добавления | Общий feedback вызывает vibrate(8), когда API поддерживается устройством. |
| Нижние кнопки скачут / дублируются | Fixed-кнопки находятся непосредственно в body; повторная инициализация удаляет старые элементы и таймер. В публичном каталоге по одной кнопке поиска и корзины. |
| Открытие/закрытие товара обновляет каталог | Router игнорирует popstate в пределах той же страницы; старые обработчики карточек не работают после удаления их DOM. |
| Переходы главная ↔ каталог | Один router собирается для обеих страниц, включая прямой вход в каталог; общий CSS миниатюр загружается при каждом переходе. Ссылки на разделы и модифицированные клики не перехватываются. |
| Шапка слишком низко в Telegram | Убрано применение safe-area-inset-top к sticky top. Реальная проверка Telegram iOS/Android остаётся обязательной; viewport-эмуляция не доказывает исправление. |
| Обводка модалок/товара | В текущем CSS desktop qv-box имеет outline и inset-границу; общий viewer и MV.sheet используют мягкую полупрозрачную границу. |
| Отзывы, фото и раскрытие | Сохранены компактные три карточки, «Смотреть все», MV.sheet для полного текста и общий viewer для фото. Нужен финальный повторный проход после всех переходов. |
| Белые полосы при загрузке и сброс скролла | Router сбрасывает scroll при смене страницы. Полная перезагрузка и browser chrome должны проверяться отдельно на реальных устройствах. |

## Проверки

- `python build.py`.
- Проверка синтаксиса miraven.js, catalog.js, qv.js, image-viewer.js.
- `node --test tests/product-card.test.js tests/router.test.js`.
- Локальный UTF-8 предпросмотр с настоящими публичными данными товаров; Tilda API не отдаёт данные localhost напрямую.
- В браузере: 320×568, 390×844 и desktop-геометрия карточки; видимость покупки; прокрутка; синхронизация категорий; общий просмотрщик `1 / 3 → 2 / 3`.
- На публичной странице: покупка из карточки, категория «Свечи» (6 товаров), стык шапки/мини-меню, отсутствие дубликатов нижних кнопок.

## Оставшая приёмка

Полный цикл на настоящих iPhone Safari, iOS Telegram, Android Chrome и Android Telegram: вертикальный скролл без случайного открытия, один tap открывает товар, свайпы фото и закрытия, покупка, системная «Назад», переходы, keyboard/browser chrome, полная перезагрузка без белых полос. Отдельно повторить цикл главная → товар → фото → закрытие → каталог → товар → назад → главная → отзыв → фото.
