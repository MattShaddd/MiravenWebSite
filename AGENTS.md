# Miraven website workflow

- This directory is the active repository for `miraven.ru`.
- Edit source files here; do not edit generated files in `dist/` directly.
- Run `python build.py` after source changes and verify the generated output relevant to the change.
- Preserve unrelated work already present in the working tree.
- For normal site-change requests, commit the verified change and push it to `origin/main`. Keep changes local only when the user explicitly requests a draft or says not to publish.
- Public pages: `https://miraven.ru/` and `https://miraven.ru/store`.
