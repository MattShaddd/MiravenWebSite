# Миравен: сайт на Тильде

Код страницы лежит здесь, на Тильде стоит только загрузчик (`loader.html`).

| Файл | Что внутри |
|---|---|
| `miraven.html` | разметка страницы |
| `miraven.css` | стили |
| `miraven.js` | скрипты: каталог из API Тильды, корзина, поиск, тема |
| `logo-*.webp` | логотипы |
| `loader.html` | вставляется один раз в блок T123 на Тильде |

Правите файлы, пушите в `main`, GitHub Pages публикует их за ~1 минуту, и сайт обновляется сам.
