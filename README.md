# Миравен: сайт на Тильде

Код страниц лежит здесь, на Тильде стоят только загрузчики.

| Файл | Что внутри |
|---|---|
| `miraven.html` / `.css` / `.js` | главная страница |
| `catalog.src.js`, `catalog.css`, `catalog.main.html` | каталог: исходники |
| `catalog.html`, `catalog.js` | **собираются** командой `python build.py`, их нужно коммитить |
| `qv.js` | **собирается** тем же `build.py` из кусков `catalog.src.js`: шторка товара для главной (подгружается при первом заходе). Вручную не править, коммитить |
| `members.css` | оформление окна входа и регистрации (личный кабинет Тильды) |
| `members.js` | скрипт страниц личного кабинета (/members/…): «Выйти» ведёт на сайт, а не на страницу входа Тильды. Подключается блоком T123 на этих страницах: `<script src="https://mattshaddd.github.io/MiravenWebSite/members.js"></script>` |
| `loader.html` | загрузчик главной (блок T123 на главной) |
| `preloader.snippet.js` | экран загрузки (логотип и полоса, которая заполняется по мере загрузки файлов). **Вшивается** `build.py` в `loader.html` и `loader-catalog.html` между метками `PRELOADER:BEGIN/END`, править нужно его, а не загрузчики. Логотип: `assets/preloader/logo.png` (оригинал) и `logo-280.webp` (подгружается по `BASE`) |
| `loader-catalog.html` | загрузчик каталога (блок T123 на странице `/store`) |
| `site-common.js` | общий скрипт для **всех** страниц: ранняя тема и баннер cookies. Подключается один раз в Тильде: Настройки сайта → Вставка кода → HTML-код для HEAD: `<script src="https://mattshaddd.github.io/MiravenWebSite/site-common.js" defer></script>`. Выбор посетителя: `MVCookies.get()` (`all` / `necessary`), `MVCookies.allowed()`, событие `mv-cookies`; повторно показать баннер: `MVCookies.reset()` |
| `legal.src.css` | оформление юридических страниц (`/oferta`, `/politika`) поверх блоков Тильды: **тексты остаются редактируемыми** в Тильде. Попадает в `members.css`. Новые такие страницы: добавить alias в `LEGAL_ALIASES` в `build.py` |
| `successpage.html`, `quicklink.html`, `pages.css`, `loader-page.template.html` | отдельные страницы «Спасибо за заказ» (`/successpage`) и мультиссылка (`/quicklink`). Загрузчики `loader-successpage.html` и `loader-quicklink.html` собираются `build.py` из шаблона; вставляются в блок T123 одноимённых страниц Тильды |
| `footer.html` / `footer.css` | отдельный глобальный футер |
| `loader-footer.html` | загрузчик для T123 на странице-футере Tilda |
| `build.py` | сборка каталога и готовых блоков без загрузчика в `dist/` |

## Как обновлять
Общий стиль выпадающих списков находится в `dropdowns.css`: он автоматически включается в магазин и сборку `members.css`. Для новых кастомных списков используйте `.mv-dropdown` и `.mv-dropdown__item` с корректной семантикой и существующей логикой управления; не создавайте отдельную палитру. Адаптеры Tilda сохраняют её обработчики выбора. Нативные `select` получают цвета темы, но внешний вид системного окна выбора зависит от браузера.

1. Правите исходники.
2. Если менялись исходники каталога, шапка, вход, тема или футер, запустите `python build.py`.
3. `git add -A && git commit -m "..." && git push`. Сайт обновится через минуту.

## Экран загрузки
Появляется, пока загрузчик скачивает файлы сайта, и закрывается, когда страница готова (не раньше чем через 0,6 с, чтобы полоса успела заполниться). Цвет фона берётся из темы (`miraven-theme` в localStorage или системная). Он живёт в загрузчиках, поэтому после `python build.py` и пуша **надо заново вставить `loader.html` (главная) и `loader-catalog.html` (каталог) в блоки T123 на Тильде**: сам загрузчик на Тильде не обновляется.

## Глобальный футер в Tilda
1. Создайте отдельную страницу `Footer` без шапки и подвала.
2. Добавьте на неё один блок T123 и вставьте содержимое `loader-footer.html`.
3. Опубликуйте страницу.
4. В настройках сайта Tilda назначьте страницу `Footer` общим подвалом и переопубликуйте все страницы.

Загрузчик получает актуальные `footer.html` и `footer.css` из GitHub Pages, поэтому последующие правки футера не требуют повторной вставки кода в Tilda.

## Финальная версия без загрузчика
`python build.py` кладёт в `dist/` файлы `miraven-tilda-T123.html`, `catalog-tilda-T123.html` и `footer-tilda-T123.html`: их целиком вставляют в блок T123 вместо загрузчика.
