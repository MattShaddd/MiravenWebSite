# Миравен: сайт на Тильде

Код страниц лежит здесь, на Тильде стоят только загрузчики.

| Файл | Что внутри |
|---|---|
| `miraven.html` / `.css` / `.js` | главная страница |
| `catalog.src.js`, `catalog.css`, `catalog.main.html` | каталог: исходники |
| `catalog.html`, `catalog.js` | **собираются** командой `python build.py`, их нужно коммитить |
| `members.css` | оформление окна входа и регистрации (личный кабинет Тильды) |
| `loader.html` | загрузчик главной (блок T123 на главной) |
| `loader-catalog.html` | загрузчик каталога (блок T123 на странице `/newstore`) |
| `build.py` | сборка каталога и готовых блоков без загрузчика в `dist/` |

## Как обновлять
1. Правите исходники.
2. Если менялись `catalog.src.js`, `catalog.main.html` или шапка/подвал/вход/тема в `miraven.*`, запустите `python build.py`.
3. `git add -A && git commit -m "..." && git push`. Сайт обновится через минуту.

## Финальная версия без загрузчика
`python build.py` кладёт в `dist/` файлы `miraven-tilda-T123.html` и `catalog-tilda-T123.html`: их целиком вставляют в блок T123 вместо загрузчика.
